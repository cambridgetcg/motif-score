    Notes in the margin

    What makes a
    shared rhythm?

    I.

    A record is not a command.

    Arrival, observation and acknowledgement are separate gestures. None is a simulated send.

    II.

    A pause has meaning.

    An unsent note is cancelled. Resuming opens the room; it does not revive that note.

    III.

    A return is not a resend.

    Inspecting an outcome adds a record, not an attempt. A missing answer stays unknown.
